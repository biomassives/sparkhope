## Overview

SparkHope provides tools for:

- **Specimen Management** - Track cultures, samples, and generations
- **Collection Organization** - Manage storage racks and locations
- **Species Database** - Catalog fungal species
- **Research Projects** - Coordinate cultivation efforts
- **Field Notes** - Document observations
