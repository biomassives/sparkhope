Preparation Instructions
  1. Measure 1000ml of distilled or spring water into a clean container
  2. Add each ingredient in the order listed above, stirring thoroughly between additions
  3. Adjust pH to target value of 6.5 if necessary using citric acid or baking soda
  4. Transfer to sterilizable jars or bottles, filling only 2/3 full to allow for expansion
  5. Sterilize using Autoclave (121°C, 15psi) for 15-20 minutes
  6. Allow to cool to room temperature before inoculation
  7. Inoculate with desired culture using sterile technique
  8. Incubate at appropriate temperature (typically 70-75°F / 21-24°C)
  9. Expected colonization time: 7-10 days
  10. Shake gently every 2-3 days to distribute mycelium
